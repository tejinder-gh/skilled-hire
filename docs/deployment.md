# Deployment

Deploy each Next.js app to Vercel or as a container. Deploy API and worker containers to ECS/Fargate behind a TLS load balancer, with managed PostgreSQL, Redis, S3, secret manager, CDN and centralized logs/traces. Run migrations as a one-off release task. Back up PostgreSQL with point-in-time recovery and test restore procedures. Configure separate production webhook secrets and restrict CORS to deployed app origins.
